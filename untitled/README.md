# 📜 Règlement officiel — Purple RP

## 📜 RÈGLEMENT OFFICIEL

| GÉNÉRAL • LÉGAL | Version de travail |
| --------------- | ------------------ |

Des règles simples à lire, précises et applicables à tous.

### 👋 Introduction

Les bases à connaître avant de rejoindre Purple RP.

{% hint style="info" %}
#### Principes essentiels

Purple RP est un serveur basé sur le RolePlay et le fair-play.

Chaque joueur incarne un personnage avec une histoire, des valeurs et des limites.

Les actions doivent rester cohérentes avec la situation RP.

**INTERDIT** Triche, glitch, duplication, mod menu et exploitation de bugs interdits.

**À RETENIR** En cas de doute, demandez au staff avant d’agir.
{% endhint %}

{% hint style="info" %}
#### Responsabilité du joueur

Lire les règles liées à son activité.

Respecter les scènes et éviter tout raccourci HRP.

Accepter les sanctions en cas d’infraction.

**À RETENIR** Le staff peut faire évoluer le règlement.
{% endhint %}

{% hint style="info" %}
**INFO** Le règlement général s’applique à tous. Les sous-dossiers servent à préciser les procédures et cas particuliers.
{% endhint %}

{% hint style="warning" %}
**🚨 VÉHICULE STAFF — McLAREN**

→ La McLaren Staff est un véhicule utilitaire de la Haute Administration.\
→ Sa présence indique qu’une intervention Staff est en cours.\
→ Le Staff prend le lead de la scène et ses consignes doivent être respectées.\
→ L’histoire et le déroulement de la scène RP continuent normalement.\
→ La scène n’est annulée que sur décision du Staff.

**🚗 PIT AVEC LA McLAREN STAFF**

❌ Il est interdit d’effectuer volontairement un PIT avec la McLaren Staff.\
→ La McLaren étant une hypercars, elle ne doit pas être utilisée pour effectuer des PIT.\
→ Tout membre du Staff effectuant volontairement un PIT avec ce véhicule pourra recevoir une sanction administrative.

_👉 McLaren Staff = intervention Staff, pas véhicule de poursuite._
{% endhint %}

### ⚖️ 1. Règlement général

Règles communes à tous les joueurs.

{% stepper %}
{% step %}
#### 🎭 RP / HRP

Restez dans votre personnage pendant les scènes.

**INTERDIT** Pas de discussion HRP ou d’information extérieure pour obtenir un avantage.
{% endstep %}

{% step %}
#### 🧠 Metagaming

Utiliser une information obtenue en HRP en RP est interdit.

**INTERDIT** Discord, stream, message privé, vocal externe, etc.
{% endstep %}

{% step %}
#### 💪 Powergaming

Pas d’action impossible ou irréaliste pour obtenir un avantage.
{% endstep %}

{% step %}
#### 🤝 Force RP

Ne pas imposer une action ou son résultat à un autre joueur.

**À RETENIR** Laissez toujours une possibilité de réaction.
{% endstep %}

{% step %}
#### 😨 Fear RP / No Fear

Votre personnage doit craindre pour sa vie lorsqu’elle est menacée.

**INTERDIT** Pas de No Fear.
{% endstep %}

{% step %}
#### 🩹 Pain RP / No Pain

Jouez correctement les blessures et leurs conséquences.

**INTERDIT** Une blessure grave ne permet pas de repartir normalement.
{% endstep %}

{% step %}
#### 🚔 Cop Bait

Interdit de provoquer volontairement les forces de l’ordre pour déclencher une poursuite.
{% endstep %}

{% step %}
#### 🔫 RDM / Freekill

Interdit de tuer ou tirer sans raison RP valable.
{% endstep %}

{% step %}
#### 🚗 VDM / Car Kill

Interdit d’utiliser volontairement un véhicule pour blesser ou tuer sans raison RP.
{% endstep %}

{% step %}
#### 🔑 Car Jacking

Un vol de véhicule doit avoir un contexte RP.

**INTERDIT** Pas d’éjection gratuite uniquement pour voler une voiture.
{% endstep %}

{% step %}
#### 🏆 Win RP

Une scène n’est pas une compétition.

**À RETENIR** Acceptez de perdre une scène lorsque le RP le justifie.
{% endstep %}

{% step %}
#### 🔄 Revenge Kill

Interdit de revenir se venger après un coma ou une mort.
{% endstep %}

{% step %}
#### 🚪 Combat Logging

Interdit de quitter une scène pour éviter ses conséquences.

**INTERDIT** ALT+F4 ou déconnexion volontaire pendant une scène.
{% endstep %}

{% step %}
#### ↩️ Retour sur scène

Après un coma ou une neutralisation, interdiction de revenir immédiatement sur la même scène.
{% endstep %}

{% step %}
#### 🛡️ Zones Safe / Mass RP

Les zones Safe sont protégées.

**INTERDIT** Pas d’arme, braquage, agression ou activité illégale.

**INTERDIT** Pas de retour en zone pour fuir une scène.
{% endstep %}

{% step %}
#### 🏥 Coma

**INTERDIT** Interdit de parler ou d’agir normalement pendant un coma.

**À RETENIR** Le coma n’est pas une Mort RP.
{% endstep %}

{% step %}
#### 🧩 Mémoire après coma

Après un coma, vous perdez les 5 dernières minutes avant le coma.

**INTERDIT** Ces informations ne peuvent plus être utilisées en RP.

{% hint style="warning" %}
**À RETENIR** En cas d’abus répétés, la durée peut passer à 10 minutes.
{% endhint %}
{% endstep %}

{% step %}
#### ⚰️ Mort RP

Une Mort RP doit respecter les règles et validations du serveur.

**À RETENIR** Après un wipe, l’ancienne vie ne doit plus être utilisée.
{% endstep %}

{% step %}
#### 🐛 Bug Abuse

**INTERDIT** Interdit d’exploiter un bug pour obtenir un avantage.

**À RETENIR** Les bugs doivent être signalés au staff.
{% endstep %}

{% step %}
#### 📺 Stream Snipe

**INTERDIT** Interdit d’utiliser un stream ou une vidéo en direct pour obtenir une information RP.
{% endstep %}

{% step %}
#### 🎙️ Double Vocal

**INTERDIT** Interdit d’utiliser plusieurs moyens de communication pour obtenir un avantage RP.
{% endstep %}

{% step %}
#### 🎒 Freeloot

**INTERDIT** Interdit de vider abusivement l’inventaire d’un joueur inconscient ou incapable de se défendre.
{% endstep %}

{% step %}
#### 🛞 Conduite RP

La conduite doit rester cohérente avec le véhicule et le terrain.

Les gros accidents doivent être joués.
{% endstep %}

{% step %}
#### 🏔️ Off-Road

Un véhicule adapté au tout-terrain peut rouler vite sur la terre.

**À RETENIR** Montagnes et fortes pentes = véhicule adapté obligatoire.

**INTERDIT** Un véhicule non adapté ne peut pas utiliser le terrain pour gagner un avantage RP.
{% endstep %}

{% step %}
#### ⚔️ Combat

Une fusillade doit avoir un contexte RP cohérent.

**INTERDIT** Pas de tir gratuit.
{% endstep %}

{% step %}
#### 🤝 Respect

Respect obligatoire entre joueurs.

Les insultes RP restent possibles si elles sont dans le contexte.

**INTERDIT** Harcèlement, discrimination, menaces HRP et insultes graves interdits.
{% endstep %}

{% step %}
#### ⛔ Contenu interdit

**INTERDIT** Viol et agressions sexuelles interdits.

**INTERDIT** RP sexuel forcé interdit.
{% endstep %}

{% step %}
#### 🧩 Mods

**INTERDIT** Les mods donnant un avantage sont interdits.

**À RETENIR** Chaque joueur est responsable des mods installés sur son jeu.
{% endstep %}

{% step %}
#### 👮 Staff

Les décisions et interventions du staff doivent être respectées.

Les litiges passent par les moyens prévus à cet effet.
{% endstep %}

{% step %}
#### 💡 Bon sens RP

Une règle ne doit pas être contournée volontairement.

**À RETENIR** Le fair-play passe avant la recherche de victoire.
{% endstep %}
{% endstepper %}

### 🏛️ 2. Règlement légal

Services publics, Gouvernement, Forces de l’ordre, EMS et entreprises.

{% hint style="info" %}
#### Principe général

Chaque métier légal respecte le règlement général.

Le règlement interne d’un métier peut préciser son fonctionnement.

**INTERDIT** Il ne peut pas contredire le règlement de Purple RP.
{% endhint %}

#### 🏛️ 2.1 Gouvernement

Règlement du pouvoir exécutif.

{% stepper %}
{% step %}
#### Rôle

Représenter l’État et gérer la ville.

Collaborer avec les services publics.
{% endstep %}

{% step %}
#### Comportement

Rester professionnel et respectueux.

**INTERDIT** Pas de décisions liées à un conflit personnel.
{% endstep %}

{% step %}
#### Lois

Proposer et appliquer des lois cohérentes avec le RP.

Informer les citoyens des nouvelles lois.
{% endstep %}

{% step %}
#### Système d’alerte

Le Gouvernement peut déclencher un niveau d’alerte selon la menace.

* 🟢 Niveau 1 — Normal : situation normale.
* 🟡 Niveau 2 — Vigilance : surveillance renforcée.
* 🟠 Niveau 3 — Menace importante : forces de l’ordre renforcées.
* 🔴 Niveau 4 — Menace majeure : forces de l’ordre fortement armées et mobilisées.

**À RETENIR** L’alerte doit être justifiée par le RP.
{% endstep %}

{% step %}
#### Informations

Garder les informations sensibles confidentielles.

**INTERDIT** Pas de fuite ou d’utilisation personnelle.
{% endstep %}

{% step %}
#### Abus de pouvoir

Ne pas utiliser son statut pour obtenir un avantage.

**INTERDIT** Pas de favoritisme, d’aide personnelle ou d’intervention abusive.
{% endstep %}

{% step %}
#### Services publics

Collaborer avec LSPD, BCSO, FIB, EMS et les autres services légaux.

**INTERDIT** Pas d’intervention sans raison RP.
{% endstep %}

{% step %}
#### Contrôle des entreprises

Le Gouvernement peut visiter et contrôler les entreprises.

**À RETENIR** Fermeture d’une entreprise = validation obligatoire du staff.
{% endstep %}

{% step %}
#### Matériel gouvernemental

Le matériel de l’État est réservé au service.

**INTERDIT** Pas de vente, don ou détournement.

**INTERDIT** Pas de transfert sans autorisation.
{% endstep %}

{% step %}
#### Élections

Les élections doivent rester sérieuses et RP.

Les campagnes respectent l’histoire de la ville.
{% endstep %}

{% step %}
#### Dictature

La dictature est autorisée si prévue par le scénario.

**À RETENIR** Carte blanche au Gouvernement pendant la dictature.

Les actions doivent suivre le dossier « Dictature ».
{% endstep %}

{% step %}
#### Justice / DOJ

Le DOJ reste indépendant.

Les décisions judiciaires doivent rester cohérentes avec le RP.
{% endstep %}

{% step %}
#### Activité illégale

Gouvernement et DOJ ne doivent pas participer à des activités illégales.

**À RETENIR** Une implication peut entraîner de lourdes sanctions.
{% endstep %}

{% step %}
#### Bon sens

Respecter le RP, l’histoire de la ville et le fair-play.
{% endstep %}
{% endstepper %}

#### 🚓 2.2 Forces de l’ordre

Règlement commun LSPD / BCSO / FIB / USSS.

{% stepper %}
{% step %}
#### Rôle

Protéger les citoyens et faire respecter la loi.
{% endstep %}

{% step %}
#### Comportement

Rester professionnel et respectueux.

Respecter la hiérarchie et les autres services.

**INTERDIT** Pas de provocation ni d’abus.
{% endstep %}

{% step %}
#### Service

Tenue et équipement adaptés au service.

Radio active pendant le service.

**INTERDIT** Pas d’intervention hors service.
{% endstep %}

{% step %}
#### Armes

Utiliser une arme uniquement si la situation le justifie.

La force doit être adaptée à la menace.

**INTERDIT** Pas de tir gratuit.
{% endstep %}

{% step %}
#### Sommations

**3 sommations avant ouverture du feu lorsque la situation le permet.**

**À RETENIR** L’arme à feu reste le dernier recours.
{% endstep %}

{% step %}
#### Contrôles / Arrestations

Toute intervention doit avoir une raison RP.

**INTERDIT** Pas d’arrestation ou de fouille gratuite.
{% endstep %}

{% step %}
#### Fouilles / Saisies

Une fouille doit être justifiée par le RP ou la procédure.
{% endstep %}

{% step %}
#### Poursuites

Conduite adaptée à la situation et au véhicule.

**INTERDIT** Pas de poursuite provoquée volontairement.
{% endstep %}

{% step %}
#### Renforts

Les renforts doivent être justifiés par la situation.

Les opérations importantes sont coordonnées par la hiérarchie.
{% endstep %}

{% step %}
#### Taser

Le Taser est utilisé uniquement lorsque la situation le justifie.
{% endstep %}

{% step %}
#### Radio / Communication

Radio claire et professionnelle.

**INTERDIT** Pas de communication HRP pour obtenir un avantage.
{% endstep %}

{% step %}
#### Confidentialité

Les informations obtenues grâce au métier restent confidentielles.

**INTERDIT** Pas de transmission abusive.
{% endstep %}

{% step %}
#### Véhicules

Les véhicules de service sont réservés au travail.

**INTERDIT** Pas d’utilisation personnelle.
{% endstep %}

{% step %}
#### Fourrière

Un véhicule ne peut être mis en fourrière qu’avec une raison RP valable.

**INTERDIT** Pas de sanction personnelle.
{% endstep %}

{% step %}
#### DEFCON

Les forces de l’ordre respectent le niveau d’alerte décidé par le Gouvernement.

**À RETENIR** Les mesures autorisées dépendent du niveau d’alerte.
{% endstep %}

{% step %}
#### Abus de pouvoir

**INTERDIT** Interdit d’utiliser son grade, son arme, son véhicule ou ses accès pour un avantage personnel.
{% endstep %}

{% step %}
#### Activités illégales

Les membres des forces de l’ordre ne doivent pas participer à des activités illégales hors cadre autorisé.
{% endstep %}

{% step %}
#### Corruption

La corruption est autorisée uniquement dans le cadre du dossier « Corruption FDO ».

**À RETENIR** Le dossier précise les conditions et limites.
{% endstep %}
{% endstepper %}

#### 🚑 2.3 EMS

Règlement des services médicaux.

{% stepper %}
{% step %}
#### Rôle

Secourir les citoyens et rester neutre.
{% endstep %}

{% step %}
#### Comportement

Rester professionnel et respectueux.

**INTERDIT** Pas de favoritisme ou d’abus.
{% endstep %}

{% step %}
#### Service

Tenue et véhicule de service en intervention.

**INTERDIT** Pas de soin ou réanimation hors service.
{% endstep %}

{% step %}
#### Interventions

Ne pas intervenir tant qu’une scène RP est en cours.

Attendre la fin de la scène avant de soigner.
{% endstep %}

{% step %}
#### Soins

Jouer les blessures de manière réaliste.

**INTERDIT** Pas de soin irréaliste ou de réanimation abusive.
{% endstep %}

{% step %}
#### Confidentialité

Les informations médicales restent confidentielles.

**INTERDIT** Pas de transmission abusive.
{% endstep %}

{% step %}
#### Matériel médical

Le matériel médical est réservé au service.

**INTERDIT** Pas de vente, don ou détournement.
{% endstep %}

{% step %}
#### Activités illégales

Les EMS ne participent pas aux activités illégales.

**INTERDIT** Pas d’aide volontaire à une organisation criminelle.
{% endstep %}

{% step %}
#### Scènes avec les FDO

Respecter les consignes des forces de l’ordre.

**À RETENIR** La sécurité des EMS reste prioritaire.
{% endstep %}

{% step %}
#### Abus de fonction

**INTERDIT** Interdit d’utiliser le métier pour favoriser un proche ou obtenir un avantage personnel.
{% endstep %}

{% step %}
#### Bon sens RP

Jouer les interventions sérieusement et privilégier le RP.
{% endstep %}
{% endstepper %}

#### 🏢 2.4 Entreprises

Règles communes aux entreprises légales.

{% stepper %}
{% step %}
#### Rôle

Chaque entreprise doit avoir une activité cohérente avec le RP.

Le patron est responsable de son entreprise.
{% endstep %}

{% step %}
#### Comportement

Employés professionnels pendant le service.

Respect des clients, collègues et autres entreprises.
{% endstep %}

{% step %}
#### Tenue & véhicules

Tenue et véhicule de service lorsqu’ils sont nécessaires.
{% endstep %}

{% step %}
#### Service

Respecter les horaires et consignes de l’entreprise.

Le patron peut définir ses propres règles internes.
{% endstep %}

{% step %}
#### Argent

L’argent de l’entreprise sert à son activité.

**INTERDIT** Pas de détournement abusif.
{% endstep %}

{% step %}
#### Employés

Le patron peut recruter, former, promouvoir et sanctionner selon son règlement interne.

**À RETENIR** Le règlement interne doit respecter Purple RP.
{% endstep %}

{% step %}
#### Publicité

La publicité doit rester liée à l’activité de l’entreprise.

**INTERDIT** Pas de spam.
{% endstep %}

{% step %}
#### Relations

Les entreprises peuvent créer des partenariats RP.

Les conflits restent dans un cadre RP.
{% endstep %}

{% step %}
#### Activités illégales

Une entreprise légale ne participe pas à une activité illégale sans cadre RP autorisé.
{% endstep %}

{% step %}
#### Contrôle du Gouvernement

Le Gouvernement peut visiter et contrôler une entreprise.

**À RETENIR** Fermeture = validation staff obligatoire.
{% endstep %}

{% step %}
#### Règlement interne

Chaque patron peut créer son règlement interne.

Il peut préciser horaires, salaires, grades, formations et sanctions internes.

**INTERDIT** Il ne peut pas contredire le règlement de Purple RP.
{% endstep %}

{% step %}
#### Bon sens

Une entreprise doit créer du RP et faire vivre son activité.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
La partie illégale sera ajoutée après validation des règles du serveur.
{% endhint %}

### 🕵️ 3. RÈGLEMENT ILLÉGAL

#### 🔫 ARMEMENT - GANGS

* Tous les membres du gang peuvent utiliser des mitraillettes et des fusils d’assaut.
* L’armement doit rester cohérent avec la scène RP.
* Interdit d’utiliser une arme uniquement pour obtenir un avantage RP.

#### 🏴 ORGANISATION / GANG / MC

* Respecter la hiérarchie et le fonctionnement du groupe.
* Les alliances sont autorisées si elles sont cohérentes RP.
* Une guerre doit avoir une raison RP valable.
* Interdit d’intervenir dans une guerre qui ne vous concerne pas.
* Le Fear-Orga doit être respecté dans les situations concernées.
* Les QG et quartiers illégaux ne sont pas des zones Safe.
* Les tenues et éléments d’identification du groupe doivent être respectés.

#### 📝 CRÉATION D’UN GROUPE ILLÉGAL

* Toute création de gang, organisation, MC, famille, cartel ou mafia doit être validée par le staff.
* Le groupe doit avoir une histoire et une identité propres.
* Le projet doit avoir pour but de créer du RP.
* Les conditions de création seront définies selon les demandes reçues et l’évolution de Purple RP.

#### 👤 INDÉPENDANT

* Un indépendant peut agir seul ou avec un petit groupe.
* Fear-Orga obligatoire.
* Interdit de revendiquer un territoire ou un point de drogue.
* Interdit d’appartenir simultanément à une organisation structurée.
* Toute attaque doit avoir une raison RP valable.
* L’armement autorisé sera défini par Purple RP.

#### 🏦 BRAQUAGES

* Un braquage doit avoir une raison RP valable.
* Laisser le temps aux FDO d’intervenir.
* La poursuite doit rester cohérente.
* Interdit de braquer juste pour provoquer une fusillade.
* Interdit de braquer juste avant un reboot.

#### 👥 PRISES D’OTAGES

* 1 braqueur peut avoir jusqu’à 2 otages.
* La prise d’otage doit avoir une raison RP valable.
* Les otages doivent être réellement impliqués dans la scène.
* Interdit de prendre un otage uniquement pour éviter une arrestation.
* Un membre des FDO ne peut être pris en otage que dans une situation RP cohérente.

#### 🗺️ TERRITOIRES & VENTE DE DROGUE

* Les territoires sont contrôlés par les gangs ou organisations.
* Une prise de territoire doit avoir une raison RP valable.
* Les ventes de drogue doivent respecter le groupe qui contrôle la zone.
* Un groupe peut autoriser un autre groupe à vendre sur son territoire.
* Une vente sur un territoire adverse peut entraîner une confrontation RP.
* Les FDO peuvent intervenir lors d’une vente.

#### 🧪 LABOS DE DROGUE

* Une descente doit avoir une raison RP valable.
* Une phase de discussion doit avoir lieu avant l’ouverture du feu lorsque la situation le permet.
* Le Fear RP doit être respecté.
* Après une défaite, il est interdit de relancer immédiatement une autre attaque sans respecter les règles prévues.
* Les horaires, limites et délais seront définis selon le fonctionnement de Purple RP.

## 🎰 CASINO CLANDESTIN

→ **Tout joueur peut organiser ou participer à un casino clandestin, y compris les chefs d’entreprises légales.**\
→ Il n’est pas nécessaire d’appartenir à une organisation illégale.\
→ Le casino clandestin doit être entièrement joué en RP.\
→ En cas d’intervention des forces de l’ordre, les participants doivent assumer les conséquences RP.

## 🔖 VOL ET UTILISATION DE PLAQUES

→ Le vol d’une plaque est autorisé uniquement dans le cadre d’une scène RP cohérente.\
→ Le changement de plaque doit être réalisé à travers une véritable action RP.\
❌ Il est interdit de changer instantanément une plaque sans action RP.\
→ Une plaque volée ne rend pas le véhicule invisible aux forces de l’ordre.\
→ Les caméras, contrôles ou témoins peuvent permettre d’identifier le véhicule.\
→ L’utilisation d’une fausse plaque peut entraîner des conséquences RP supplémentaires.\
❌ Il est interdit de voler ou cloner les plaques de véhicules officiels (LSPD, BCSO, SAFR, Gouvernement, etc.) sauf dans le cadre d’une scène RP autorisée.

#### ⚠️ RÈGLE FINALE

* Le règlement général s’applique à tous les joueurs, toutes les fonctions et toutes les organisations.
* Les sous-dossiers servent à apporter des précisions.
* Le staff peut sanctionner tout comportement visant volontairement à contourner le règlement ou à casser le RP.
